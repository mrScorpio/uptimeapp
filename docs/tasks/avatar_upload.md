##  [C] Context

мы хотим чтобы пользователь мог загрузить свой аватар в профиле

##  [O] Objective / Цель, результат

пользователь заходит в редактирование профиля, нажимает "загрузить аватар", выбирает изображение подходящего формата, у него появляется новый аватар и после нажатия кнопки "сохранить" изображение сохраняется в папке, а в профиле и в верхней панели отображается новый аватар

##  [S] Scope / Границы

аватары хранятся в отдельной локальной папке, которую нужно исключить из git, и из этой же папки раздаются на фронтэнд

##  [T] Test

выполни тест загрузки аватара и проверь работу нового API
